
# Quantum Sprint — H₂ Ground-State Energy Estimation

**Event:** IBM Qiskit Fall Fest 2026  
**Problem:** PS-C1 — H₂ Ground-State Energy Estimation  
**Method:** Variational Quantum Eigensolver (VQE)

## Project Overview

This project explores the Variational Quantum Eigensolver (VQE), a hybrid quantum-classical algorithm for estimating the lowest eigenvalue of a Hamiltonian.

The current implementation uses a precomputed, symmetry-reduced two-qubit Hamiltonian associated with an H₂ model. It runs VQE with a statevector estimator and compares the result with exact classical diagonalization of the same Hamiltonian.

**Scope note:** This is a reduced-model baseline. The full molecular-integral workflow using Qiskit Nature and PySCF has not yet been validated in this environment. The reported energy should not be treated as a verified total molecular ground-state energy until the Hamiltonian provenance, energy conventions, and benchmark geometry have been checked.

## Method

1. Define the reduced Hamiltonian as a weighted sum of Pauli operators.
2. Prepare a parameterized two-qubit ansatz.
3. Use VQE and the SLSQP optimizer to minimize the expected energy.
4. Compute the exact minimum eigenvalue classically for comparison.
5. Report the energy difference between the two methods.

## Requirements

## Run Locally

Activate your Python virtual environment, install the required packages, and run:

```bash
python h2_vqe.py
```

The script prints the VQE energy, exact eigenvalue, and absolute difference.

## Results

Results must be generated by running the script. Do not treat example values as independently verified molecular benchmark results.

The current model's output is recorded locally in `results/vqe_output.txt`. The output should be committed only after confirming it was generated by the current version of the script.
